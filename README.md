# acman

This isn't meant to be a project to use, but if you absolutely have to then it can deploy noggit projects and has a rudimentary MPQ/DBC editor. There are no real releases so you'll have to build it yourself using something like:
`npm install`
`npm run tauri build`
Then running the built executable - I believe there is an issue generating AppImages with it at the moment but I've largely put down this project to work on my noggit-red branch, if something's wrong and easily fixed then just give me a poke on discord or raise an issue on the repository.

You will need Rust / rustup installed on your machine to build this project.
